Project Overview
This project is a fully responsive, single-page personal website designed as a timeline to showcase my journey at IIT Bombay. It serves as a digital scrapbook detailing key academic, personal, and extracurricular milestones, developed as part of the Learner's Space "Fundamentals of Finance Bootcamp" weekend challenge.

Objectives Achieved
HTML Structure: Created a structured and semantic HTML document (`index.html`).

Styling & Design: Used CSS (Tailwind) for styling, focusing on layout, typography, and personalized aesthetics.

Responsiveness: Implemented a mobile-first responsive design approach using CSS media queries to ensure optimal viewing across all devices (mobile, tablet, desktop).

Interactivity: Integrated an interactive JavaScript element to enhance user engagement.

Navigation: Included a fixed navigation bar for smooth, easy access to all site sections.

Key Features
Timeline Milestones: A dedicated section that chronologically presents key events, including academic achievements, hostel memories, and fests, complete with images and anecdotes.

Learnings & Growth: Highlights the personal and academic skills gained, clubs joined, and projects completed during the journey.

Interactive Element (Timeline Selector): Uses custom JavaScript to allow users to dynamically cycle through different phases of the IITB journey (e.g., 'Semester 1', 'Hostel Life', 'Clubs') in the timeline section, making the content more engaging.

Gallery: A responsive photo grid showcasing visual highlights from the experience.

Technical Stack
HTML5: Semantic structure and content.

CSS3 (Tailwind CSS via CDN): Styling, layout, and rapid responsive design implementation.

JavaScript (ES6): Used for DOM manipulation, dynamic content display, and implementing the interactive Timeline Selector.
